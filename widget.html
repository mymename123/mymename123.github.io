블로그 업적 위젯

달성한 업적과 블로그 레벨을 내 블로그 사이드바에 걸어 두세요. 위젯을 누르면 블로랩의 내 공개 프로필로 이동해요. 숫자는 하루에도 몇 번씩 새로 읽어서 위젯에 반영돼요.

  1. 1본인 확인
  2. 2위젯 꾸미기
  3. 3내 블로그에 붙이기

내 네이버 블로그 주소

처음이면 블로그 소개글로 본인 확인을 한 번 해요. 로그인이나 비밀번호는 필요 없어요.

위젯을 만들면 블로그의 공개 숫자, 업적 달성 날짜, 위젯 설정이 블로랩 서버에 저장돼요. 공개 프로필에는 내가 고른 항목만 보이고, 진단 결과는 지금처럼 저장하지 않아요. 위젯은 언제든 지울 수 있어요. 자세히

네이버 블로그에 붙이는 법

PC 블로그의 사이드바에 보여요. 네이버 모바일 화면은 사이드바 위젯을 보여 주지 않아요.

  1. 오른쪽 삽입 코드 복사를 눌러요.
  2. 네이버 블로그 관리 → 꾸미기 설정 → 레이아웃·위젯 설정으로 가요.
  3. 아래쪽 위젯 직접등록을 누르고, 위젯 이름(예: 블로그 업적)과 복사한 코드를 붙여 넣고 다음 → 등록을 눌러요.
  4. 레이아웃 화면에서 새 위젯을 원하는 자리로 끌어 놓고 적용을 눌러요.

본문에 넣고 싶다면 그림으로 저장한 뒤 사진으로 올리고, 사진에 공개 프로필 링크를 걸어 주세요. 네이버 본문은 HTML 코드를 넣을 수 없어요.
